# Idiomas

La interfaz del estudio se publica en **español, inglés y ruso**. El español es el
idioma de origen y el **respaldo**: si falta una traducción o una clave está mal
escrita, el texto español se sigue viendo en vez de dejar un hueco o una clave
cruda en pantalla.

## Cómo funciona

Todo vive en el navegador, sin dependencias ni paso de compilación:

- `web/js/i18n.js` — núcleo: `t(clave, variables)`, `installI18n()`, `setLang()`,
  `lang()`, `onLangChange(fn)`. Resuelve `{nombre}` y elige la forma plural
  (`one` / `few` / `many` / `other`) cuando el valor es un objeto y se pasa `{n}`.
- `web/js/i18n/es.js`, `en.js`, `ru.js` — juntan los objetos de cada área.
- `web/js/i18n/<idioma>/<área>.js` — los textos, agrupados por pantalla
  (`studio`, `guest`, `home`, `devices`, `effects`, `diagnostics`, `pages`, `misc`,
  `studiojs`, `common`).

El idioma se elige en este orden: `?lang=es|en|ru` → lo guardado en
`localStorage["swr.lang"]` → `navigator.languages` → español. El selector
`[data-lang-picker]` se monta solo dentro de cada `[data-lang-slot]`, guarda la
elección y emite `swr:lang` para que las vistas dinámicas repinten sus etiquetas.

## Marcar cadenas

En el HTML el texto español se queda escrito en el marcado y sólo se le añade el
atributo, así que sin JavaScript (o con una clave inexistente) la página sigue
siendo legible:

```html
<h1 data-i18n="home.heroTitle">Tu estudio en vivo.</h1>
<button data-i18n-title="studio.saveRoom" title="Guardar sala">Guardar sala</button>
<input data-i18n-placeholder="home.roomPlaceholder" placeholder="Mi show en vivo">
```

Atributos disponibles: `data-i18n` (texto), `data-i18n-title`, `data-i18n-aria`,
`data-i18n-placeholder`.

En JavaScript:

```js
import { t, onLangChange } from "./i18n.js";

label.textContent = t("studio.sourceCount", { n: count });
onLangChange(() => label.textContent = t("studio.sourceCount", { n: count }));
```

Las constantes con etiquetas no se traducen al importar: guardan la clave o se
construyen en una función, y lo que se queda fijo en pantalla se repinta dentro de
`onLangChange`.

Cadenas plurales (objeto en las tres lenguas, con `{n}` en el texto):

```js
// es
"studio.sourceCount": { one: "{n} fuente", other: "{n} fuentes" },
// en
"studio.sourceCount": { one: "{n} source", other: "{n} sources" },
// ru
"studio.sourceCount": { one: "{n} источник", few: "{n} источника", many: "{n} источников" },
```

No se traducen nombres propios ni términos técnicos: StreamWebRom, OBS, YouTube,
Twitch, Kick, Cloudflare, WebRTC, WHIP, WHEP, PiP, SFU, Backstage, names of
devices that come from the browser, ids, classes, parámetros de URL ni claves de
almacenamiento.

## Pruebas

```bash
node --test tests/i18n.test.mjs
```

Comprueba que las tres lenguas tienen exactamente las mismas claves, que ninguna
traducción está vacía, que las formas plurales son completas, el orden de
detección del idioma, los plurales rusos y que toda clave usada en el HTML existe.
Los smokes de navegador fijan `locale='es-ES'` (y `?lang=` cuando hace falta) para
que las aserciones en español sigan valiendo.
